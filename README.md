# TeacherPortfolio

Электронное портфолио преподавателя с возможностью управления образованием, курсами повышения квалификации и категориями преподавателей.

## Описание

TeacherPortfolio - это веб-приложение для отдела кадров и преподавателей, позволяющее:
- Создавать и управлять личной информацией преподавателя
- Создавать и управлять образованием преподавателя
- Создавать и управлять курсами повышения квалификации преподавателя
- Создавать и управлять категорией преподавателя

## Технологии

- **Backend**: Java 21
- **База данных**: PostgreSQL
- **Дополнительные инструменты**: Spring Boot, Hibernate, Maven, REST, Lombook

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/MihalinaGotovchits/TeacherPortfolio.git
2. Запустить контейнер базы данных и приложение в Docker командой
   ```bash 
   docker compose up -d
